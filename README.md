# Spear Guy

A game by Porter.

A stick guy throws spears. Four levels. One of them has a tank.

## Levels

| File | What it is |
| --- | --- |
| `index.html` | Start screen |
| `level-one.html` | One guy throws back. Hearts and backflips. |
| `level-two.html` | Four guys over lava. Dominoes. |
| `level-three.html` | A tank climbing a slippery hill. |
| `level-four.html` | Thirty guys. Chain reaction. |
| `spear-lab.html` | Where the spear was invented. Just dials and a scarecrow. |

## How it's built

Plain HTML, CSS and JavaScript. No libraries, nothing to install.
Every level is one file you can open by double-clicking it.
